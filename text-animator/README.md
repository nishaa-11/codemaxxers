# text-animator

A project for generating and rendering animated mathematical content using FastAPI, Manim, and React.

## Structure

- **backend/**: FastAPI backend, LLM integration, Manim script generation
- **renderer/**: Manim helper library and templates
- **frontend/**: React app for user interaction
- **renders/**: Generated scripts, videos, and logs
- **docs/**: Documentation and presentations

See subfolders for details.
